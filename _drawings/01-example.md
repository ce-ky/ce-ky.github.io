Replace this file (or add more `.md` files next to it in `_drawings/`) to
add drawings. Each entry just needs a `title` and a `cover` image — no
`link`/`external` fields here, since drawings show in a waterfall gallery
and clicking a thumbnail always opens that same image in a popup instead
of navigating to a details page. See `_projects/01-demo-submerged.md` for
the other collections' field options (cover image, external link, etc.).
